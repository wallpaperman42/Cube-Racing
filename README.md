# Cube Racing
A three-lane arcade racing game for acubemy smart cubes.

## Controls
- R / R' = right; L / L' = left
- U / U' = speed boost; F / F' = jump
- Keyboard: Left/Right arrows, Up arrow, Space
- Touch buttons are included.

## Test
Open `index.html` in a browser to play with the keyboard. To test the plugin integration, open acubemy > Games & Plugins > Developer and drop `index.html` onto the single-file developer panel (the SDK is loaded from jsDelivr).

## Publish
Create a public GitHub repository, upload `index.html` and `acubemy-plugin.json` to its root, then paste `https://github.com/YOUR_USERNAME/cube-racing` into acubemy > Games & Plugins > Installed > Add a plugin from GitHub.

Uses the acubemy SDK v1. Cube Bluetooth pairing is managed by acubemy, not this page. Requires the SDK CDN to be reachable.
